**Description**

```
Your Launcher is a keyboard-first launcher for Windows. You build your own tree of apps, folders, files, web links and commands, and open it instantly with a global hotkey (Alt+Space by default). One search box then reaches everything: your items, open windows, system commands, a calculator, your files and your own plugins.

Your own tree
• Group items into folders and sub-folders, reorder them, move them by keyboard or drag and drop.
• Five item types: apps (with arguments, working folder and run as administrator), files and folders, URLs, and shell commands (PowerShell, cmd or pwsh; visible or hidden).
• {query} items: put {query} in a URL or command and type "keyword text", e.g. "g cats" for a Google search or "jira ABC-123" to open a ticket.
• Give any item its own global hotkey to open it without the panel.
• Drag files, folders, shortcuts and .url links from Explorer or the Start menu onto the panel, import apps from the Start menu (Store apps too), or import browser bookmarks from Chrome, Edge, Brave, Vivaldi, Opera or an HTML export.

One search box
• Fast, forgiving search across the whole tree, ranked by what you open most.
• Calculator: type 12*4+0x10, press Enter to copy the result.
• System commands: lock, sleep, hibernate, sign out, restart, shut down, empty Recycle Bin (the risky ones ask first).
• Window switcher: type part of a window title to jump to it, optionally including other virtual desktops and tiling window manager workspaces such as GlazeWM.
• File search: type "f" and a file name. Uses Everything when it is running, otherwise the Windows Search index.
• Plugins: small programs in any language (PowerShell, Python, ...) can add their own results via simple JSON.

Looks and feel
• 21 themes: Windows Light and Dark, Catppuccin, Tokyo Night, Dracula, Nord, Gruvbox, One Dark, Solarized, Monokai, GitHub and Rosé Pine, with live preview, adjustable background opacity over Mica/Acrylic, and the Windows accent color.
• English and Turkish interface.
• Fully keyboard driven: add, edit, cut, paste, duplicate and delete without touching the mouse.
• Tray icon, optional start with Windows, opens on the monitor you're working on.
• Your configuration is a plain JSON file you can back up, export and import.

The app itself makes no network connections and collects no data. Everything stays on your device.
```

## Restricted capabilities — justification (alan sınırı 500 karakter)

**runFullTrust** (481 karakter)

```
Your Launcher is a desktop (WPF) launcher, so it runs as a full-trust packaged process. It needs Win32 APIs unavailable in an AppContainer: RegisterHotKey for its hotkeys, Shell_NotifyIcon for the tray icon, ShellExecuteEx/CreateProcess to start what the user picks, EnumWindows/SetForegroundWindow to switch windows, and the local Windows Search index for file search. It reads icons and .lnk targets of the user's items. The app makes no network connections and collects no data.
```

## Submission options → Notes for certification / Additional testing information

```
Your Launcher lives in the system tray and opens with a global hotkey.

To test:
1. Launch "Your Launcher" from Start. On first run the panel opens once, and a tray icon appears.
2. Press Alt+Space to show/hide the panel (if another app already uses Alt+Space, the settings page opens so a different hotkey can be chosen). Esc hides it.
3. Press Ctrl+N to add an item: choose "App", enter "notepad.exe" as the target, save with Ctrl+Enter. Press Enter on it to launch Notepad.
4. Type a few letters to search the whole tree. Type "12*4" to see the calculator row (Enter copies the result). Type "lock" to see system commands. Type part of an open window's title to switch to it.
5. Type "f readme" to search files through the Windows Search index.
6. Ctrl+, opens Settings (hotkey, theme with live preview, language, "Start with Windows", import/export, import from Start menu).
7. Right-click the tray icon for Show, Settings and Exit.

Plugins are optional programs the user places in the plugins folder; none are installed or downloaded by the app.

Requirements: Windows 11.
```
